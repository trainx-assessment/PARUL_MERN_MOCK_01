# Getting Started

## 1. Fork the Repository

Open the assessment repository on GitHub.

Click:

**Fork**

Create the fork under your own GitHub account.

You will work on your own fork.

---

## 2. Clone Your Fork

Open your fork on GitHub.

Click:

**Code → HTTPS**

Copy the repository URL.

Open Terminal and run:

```bash
git clone https://github.com/YOUR-USERNAME/html-css-js-mock-01.git
```


Then enter the project:

```bash
cd html-css-js-mock-01
```

---

## 3. Open the Project in VS Code

Run:

```bash
code .
```

Or open the project folder directly in VS Code.

---

# Branch Setup

## 4. Create Your Assessment Branch

You must create your own branch before making any changes.

Use your name in this format:

```text
firstname-lastname
```

Example:

```text
rahul-sharma
```

Create the branch:

```bash
git checkout -b rahul-sharma
```

Verify your current branch:

```bash
git branch
```

You should see:

```text
* rahul-sharma
  main
```

The `*` indicates your current branch.

### Important

Do not work directly on `main`.

All your assessment work must be completed on your personal branch.

---

# Start the Assessment

## 5. Read the Test

Open:

```text
TEST.md
```

Read all requirements before starting.

Your task is to complete the TaskFlow application according to the requirements mentioned in `TEST.md`.

---

## 6. Start the Application

This is a frontend-only application.

You do not need:

* Node.js
* npm
* Express
* MongoDB
* React

You can open:

```text
index.html
```

directly in your browser.

You may also use the **Live Server** extension in VS Code.

---

# Save Your Work

You may commit your work regularly.

Example:

```bash
git add .
```

```bash
git commit -m "Implement task management functionality"
```

You can make multiple commits during the assessment.

---

# Submit Your Work

## 7. Push Your Branch

When you have completed the assessment, push your branch to your fork.

Example:

```bash
git push -u origin rahul-sharma
```

Replace `rahul-sharma` with your actual branch name.

---

## 8. Create Your Pull Request

Go to your GitHub fork.

You should see an option to create a Pull Request.

Create the Pull Request:

```text
YOUR FORK
    ↓
YOUR BRANCH
```

to:

```text
TRAINX-ASSESSMENT
    ↓
main
```

Your Pull Request must target the **original assessment repository**, not your fork.

---

## 9. Pull Request Title

Use this format:

```text
Submission — Your Full Name
```

Example:

```text
Submission — Rahul Sharma
```

---

# Successful Submission

Your assessment will be considered successfully submitted when:

* Your work is completed on your personal branch.
* Your branch has been pushed to your GitHub fork.
* Your final implementation is present in the branch.
* The required functionality from `TEST.md` has been completed.
* The debugging exercise has been completed.
* Your Pull Request has been created.
* The Pull Request targets the original repository's `main` branch.
* You have **not merged the Pull Request**.

---

# Important

Your Pull Request is your **official assessment submission**.

Do not merge your Pull Request.

The instructor will review your submission and the automated assessment checks will be performed on your submitted code.
